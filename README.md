# 🦁 سیستم مدیریت باغ‌وحش (Zoo Management System)

پروژه‌ای به زبان **++C** برای مدیریت اطلاعات حیوانات یک باغ‌وحش، پیاده‌سازی‌شده در قالب سه فایل مستقل که هرکدام یک نسخه از پروژه را نشان می‌دهند. این پروژه در راستای درس **مبانی برنامه‌سازی** نوشته شده است.

برنامه اطلاعات حیوانات نگه‌داری‌شده در باغ‌وحش (نام، شماره قفس، سال ورود، کمیاب بودن و وضعیت تغذیه) را از طریق ورودی استاندارد دریافت کرده و بر اساس دستورات مختلف، عملیات افزودن، جست‌وجو، ویرایش، حذف، مرتب‌سازی، تغذیه، ذخیره و بارگذاری را روی آن‌ها انجام می‌دهد.

📄 صورت کامل تمرین (شامل هر دو گام و مثال‌های ورودی/خروجی) در فایل [`PROBLEM_STATEMENT.md`](./PROBLEM_STATEMENT.md) قرار دارد.

## 📁 ساختار فایل‌ها

هر سه فایل، منطق یکسانی برای دستورات `ADD`، `SEARCH`، `LIST`، `DELETE`، `EDIT`، `SORT` و `FEED` دارند و تنها در **نحوهٔ ذخیره و بارگذاری اطلاعات در فایل** (دستورات `SAVE` و `LOAD`) با هم تفاوت دارند:

| فایل | روش ذخیره‌سازی (SAVE / LOAD) |
|---|---|
| `aval.cpp` | هر حیوان در یک خط ذخیره می‌شود؛ بارگذاری تا پایان فایل ادامه می‌یابد. |
| `dovom.cpp` | مشابه بالا، با این تفاوت که تعداد کل حیوانات پیش از **هر** رکورد نوشته می‌شود (تکراری و ناکارآمد) و بررسی باز شدن فایل نیز اضافه شده است. |
| `sevom.cpp` | نسخهٔ بهینه: تعداد حیوانات فقط یک‌بار در ابتدای فایل نوشته می‌شود و در بارگذاری، دقیقاً به همان تعداد رکورد خوانده می‌شود. |

> پیشنهاد می‌شود در صورتی که قصد دارید تنها یک نسخهٔ نهایی را منتشر کنید، نسخهٔ `sevom.cpp` را به‌عنوان نسخهٔ اصلی معرفی کنید و بقیه را در پوشه‌ای مانند `versions/` نگه دارید (در بخش پیشنهادها توضیح داده شده).

## ⚙️ دستورات پشتیبانی‌شده

| دستور | فرمت ورودی | توضیح |
|---|---|---|
| `SET` | `SET <تعداد_قفس>` | تعیین تعداد کل قفس‌های باغ‌وحش |
| `ADD` | `ADD <نام> <شماره_قفس> <سال_ورود> <کمیاب:0/1>` | افزودن حیوان جدید |
| `SEARCH` | `SEARCH name <نام>` یا `SEARCH cage_number <شماره>` | جست‌وجوی حیوان بر اساس نام یا شماره قفس |
| `LIST` | `LIST` | نمایش لیست تمام حیوانات |
| `DELETE` | `DELETE <شماره_قفس>` | حذف حیوان بر اساس شماره قفس |
| `EDIT` | `EDIT <شماره_قفس> <فیلد> [مقدار جدید]` | ویرایش یکی از فیلدهای `name`، `year_of_entry`، `is_rare`، `is_fed` |
| `SORT` | `SORT` | مرتب‌سازی الفبایی بر اساس نام (و شماره قفس در صورت تساوی) |
| `FEED` | `FEED <تعداد>` | تغذیهٔ حیوانات گرسنه، با اولویت حیوانات کمیاب و قدیمی‌تر |
| `SAVE` | `SAVE <نام_فایل>` | ذخیرهٔ اطلاعات در فایل |
| `LOAD` | `LOAD <نام_فایل>` | بارگذاری اطلاعات از فایل |
| `EXIT` | `EXIT` | پایان برنامه |

### قوانین اعتبارسنجی

- نام حیوان باید حداقل ۲ کاراکتر باشد.
- شماره قفس باید بین ۱ و تعداد کل قفس‌ها (مقدار `SET`) باشد.
- هر قفس فقط می‌تواند یک حیوان داشته باشد.

## 🛠️ نحوه کامپایل و اجرا

```bash
g++ -std=c++11 -O2 -o zoo sevom.cpp
./zoo
```

سپس دستورات را خط‌به‌خط از ورودی استاندارد وارد کنید، یا فایل ورودی را با ریدایرکت بدهید:

```bash
./zoo < input.txt > output.txt
```

### مثال اجرا

```
SET 10
ADD Simba 1 2020 1
ADD Zazu 2 2019 0
LIST
SEARCH name Simba
SAVE zoo_data.txt
EXIT
```

## 📌 فایل‌های پیشنهادی برای افزودن به مخزن

برای انتشار حرفه‌ای پروژه در گیت‌هاب، پیشنهاد می‌شود این فایل‌ها هم اضافه شوند:

1. **`.gitignore`** — برای نادیده گرفتن فایل‌های اجرایی (`*.exe`, `*.out`, `zoo`) و فایل‌های ذخیرهٔ نمونه (`*.txt` در صورت تمایل).
2. **`LICENSE`** — یک لایسنس متن‌باز (مثلاً MIT) در صورت تمایل به اشتراک‌گذاری آزاد کد.
3. **نمونه فایل ورودی/خروجی** (مثلاً `examples/sample_input.txt` و `examples/sample_output.txt`) تا کاربران بتوانند بدون نوشتن دستور، نحوهٔ کارکرد برنامه را ببینند.
4. **`Makefile`** ساده برای کامپایل خودکار هر سه نسخه یا نسخهٔ منتخب.
